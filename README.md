# OOP Midterm: Hands-On Starter Project

Open this folder in Godot 4 (Project Manager > Import > select project.godot).
Open a challenge scene and press F6 (Run Current Scene) to try it before you change anything.

## Challenge 1: res://challenge_1/challenge_1.tscn
Script to refactor: challenge_1/player_god.gd
Controls: Left/Right to move, Space to jump, Esc to take 10 damage (test key).

## Challenge 2: res://challenge_2/challenge_2.tscn
Script to redesign: challenge_2/enemy.gd (scene: challenge_2/enemy.tscn)
Controls: arrow keys move the green target.
The top enemy patrols; the bottom enemy chases the target.
challenge_2/target.gd is a test helper. You do not need to change it.

## Challenge 3: res://challenge_3/challenge_3.tscn
Scripts to redesign: challenge_3/door.gd, challenge_3/player.gd, challenge_3/hud.gd
Controls: arrow keys move the player. Walk into the brown door and press Space to open it.

Before you refactor, run each scene and note exactly what it does.
After you refactor, it must still behave the same way.
